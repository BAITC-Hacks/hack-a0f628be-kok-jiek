# FAQ-бот команды Kok Jiek

Чат в терминале на Python, который отвечает на пять вопросов про репетицию:
время, команду, трек, сдачу и призы. Нейросети, API-ключи и дополнительные
библиотеки не нужны.

## Как запустить

Нужен Python 3.

1. Скачайте репозиторий и откройте терминал в его папке.
2. Выполните `python main.py` (на Windows также можно `py main.py`).
3. Введите вопрос и нажмите Enter. Для завершения напишите `выход`.

## Что получилось

Бот читает пять пар вопрос–ответ из `faq.txt`, сравнивает слова пользователя
с ключевыми словами и печатает ответ с наибольшим количеством совпадений.
Регистр и знаки препинания не влияют на поиск. При равенстве выбирается
первая запись, а без совпадений бот отвечает «не знаю».

Примеры: «Когда начало?», «Сколько человек в команде?», «Какой трек?»,
«Как сдать работу?», «Какие призы?». На «Как приготовить пиццу?» — «не знаю».

## Как изменить ответы

Каждая из пяти строк `faq.txt` имеет формат:

```text
Вопрос | ключевые слова через пробел | Ответ
```

Сохраняйте файл в UTF-8. Точные время, размер команды, треки и призы пока
не указаны: соответствующие ответы предлагают уточнить их у организаторов.
Когда условия станут известны, замените ответы в файле.

Поиск использует точные слова: опечатки и формы слов, отсутствующие в списке
ключевых слов, не распознаются. Новые варианты можно добавить в `faq.txt`.
